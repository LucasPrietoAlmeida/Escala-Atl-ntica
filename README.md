# Escala Atlántica

Escala Atlántica es un proyecto web corporativo ficticio dedicado a ofrecer experiencias turísticas, gastronómicas y culturales a los pasajeros de cruceros que hacen escala en **A Coruña (Galicia)**.

La web permite descubrir diferentes actividades y lugares de interés de la ciudad, mostrando propuestas adaptadas al tiempo disponible de los visitantes antes de regresar a su crucero.

## Objetivo del proyecto

Desarrollar una página web moderna, atractiva y responsive que presente una empresa turística ficticia especializada en organizar experiencias para pasajeros de cruceros en A Coruña.

El proyecto busca ofrecer una experiencia de navegación sencilla e intuitiva, destacando los principales atractivos turísticos, gastronómicos y culturales de la ciudad.

## Características

- **Diseño responsive:** adaptación a dispositivos móviles, tablets y ordenadores.
- **Página de inicio:** presentación de la empresa y propuesta de valor.
- **Experiencias gastronómicas:** selección de propuestas para descubrir la gastronomía coruñesa.
- **Museos y cultura:** información sobre espacios culturales y museos de A Coruña.
- **Rutas turísticas:** lugares emblemáticos y recorridos por la ciudad.
- **Formulario de contacto:** interfaz para solicitar información sobre las experiencias.
- **Navegación intuitiva:** menú adaptado a diferentes tamaños de pantalla.
- **Diseño visual:** estética inspirada en el entorno atlántico, con una paleta de colores azul marino, blanco y tonos arena.

## Experiencias destacadas

El contenido de la web está centrado exclusivamente en A Coruña.

### Gastronomía
- Gastronomía tradicional gallega.
- Restaurantes y propuestas gastronómicas locales.
- Árbore da Veira.

### Museos y cultura
- MEGA – Mundo Estrella Galicia.
- Domus – Casa del Hombre.
- Aquarium Finisterrae.
- Museo de Belas Artes da Coruña.
- Castillo de San Antón.

### Rutas y lugares turísticos
- Torre de Hércules.
- Plaza de María Pita.
- Ciudad Vieja.
- Paseo Marítimo.
- Monte de San Pedro.
- Playas de Riazor y Orzán.

## Instalación y ejecución

No es necesario instalar dependencias ni configurar un servidor backend.

1. Clona el repositorio:

   ```bash
   git clone URL_DEL_REPOSITORIO
   ```

2. Accede al directorio:

   ```bash
   cd escala-atlantica
   ```

3. Abre el archivo `index.html` en tu navegador.

También puedes utilizar la extensión **Live Server** de Visual Studio Code para ejecutar el proyecto en un servidor local durante el desarrollo.

## Diseño responsive

La interfaz está diseñada para adaptarse a diferentes resoluciones:

- **Desktop:** navegación completa y distribución amplia del contenido.
- **Tablet:** adaptación de las secciones y tarjetas.
- **Mobile:** menú adaptado y disposición vertical de los elementos.

## Formulario de contacto

El proyecto incluye un formulario visual para que los visitantes puedan solicitar información sobre las experiencias turísticas.

**Importante:** el formulario es únicamente demostrativo. No dispone de backend y no envía ni almacena datos.

## Proyecto

**Escala Atlántica** es un proyecto empresarial ficticio desarrollado en el contexto del **Hub de Empleabilidad**, como ejercicio práctico de diseño, desarrollo web y trabajo en equipo.
